# CTD Africa — Landing Page
**ctd-africa.com** · Connect The Dots Africa · Pretean (Pty) Ltd

## Deploy to Cloudflare Pages
1. Push this folder to a GitHub repository
2. Cloudflare Dashboard → Pages → Create project → Connect to Git
3. Build settings: Framework = None, Build command = blank, Output = `/`
4. Deploy → Add custom domain `ctd-africa.com`

## After Deploy
- Submit `https://ctd-africa.com/sitemap.xml` to Google Search Console
- Create Google Business Profile for local SA search visibility
- Upload `og-image.jpg` (1200×630px) to root for social share previews
