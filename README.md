## IMPORTANT — How to deploy correctly to GitHub

The most reliable way is to replace files directly in GitHub:

1. Go to your GitHub repository
2. Click on `index.html`
3. Click the **pencil/edit icon**
4. Select all (Ctrl+A), delete everything
5. Paste the new content from the index.html in this zip
6. Click **Commit changes**
7. Cloudflare Pages will auto-redeploy within ~30 seconds

OR if pushing via Git:
```
git add -A
git commit -m "Landing page update"
git push
```
